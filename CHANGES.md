# Что изменено и что проверено

## Соединение бэкенда и фронтенда

Раньше фронтенд не обращался к API вообще: показывал 720 синтетических точек и читал CSV в браузере.
Теперь он работает с бэкендом, а при его недоступности переходит в офлайн-режим.

- Клиент API (`frontend/src/api.js`), прокси в `vite.config.js`, раздача собранного интерфейса самим FastAPI.
- Карта берёт детекции, сетку 10 км, события и связи с сервера по выбранным области, году, месяцу, сенсору, дню/ночи и потоку.
- Шкала времени показывает гармонизированный индекс из `/analytics/calendar`.
- Новая панель Harmonize: календарь горения, сезонность и аномалии, валидация модели, согласие сенсоров.
- Панель данных: загрузка CSV/ZIP на сервер с ходом импорта, загрузка встроенного примера, импорт из NASA FIRMS, покрытие, экспорт.

## Новое в бэкенде

- `GET /api/v1/overview`, `POST /api/v1/demo/load`, `POST /api/v1/harmonization/events`, `?compact=true` у модели.
- Пары в `/harmonization/matches` получили координаты и доли совпадений.
- Раздача `frontend/dist`, чтение `backend/.env`, скрипт `scripts/export_openapi.py`.

## Исправленные ошибки

Бэкенд:

- Любой внутренний `KeyError` превращался в ответ 404 и маскировал настоящие сбои. Введён отдельный `NotFoundError` только для неизвестных задач и моделей.
- `CORS_ORIGINS` с пробелами или завершающим `/` не совпадал с адресом браузера; адреса `127.0.0.1` не были разрешены по умолчанию.
- Файл `.env` из инструкции сервером не читался.

Фронтенд:

- Кнопка входа уводила в 3D-вид Шанхая, где нет данных о пожарах; теперь открывается область загруженных данных или Китай.
- Строки FIRMS с `instrument=SNPP` (так в вашем архиве Suomi) не попадали ни в MODIS, ни в VIIRS и исчезали при фильтре; сенсор теперь определяется и по спутнику.
- Импорт пустого или не-CSV файла падал с ошибкой `Cannot read properties of undefined`.
- Клик по точке при сильном приближении отдалял карту до масштаба 7.
- Подпись под счётчиком наблюдений перекрывалась кнопкой Scene settings.
- «Cursor light» был включён по умолчанию и скрывал оранжевую зону выбранного региона; по умолчанию выключен.
- Прямоугольник городского вида больше не считается областью запроса данных.
- Удалены устаревшая сборка `dist/` и вложенная копия архива проекта.
- Код из одной строки на 25 КБ разбит на читаемые модули.

## Что проверено при подготовке этой версии

В среде, где готовилась версия, не было сети и не установлены `fastapi`, `duckdb`, `shapely`, `httpx`,
`maplibre-gl`, `vite`. Поэтому:

Проверено запуском:

- Интерфейс: настоящий код `src/` собран esbuild и прогнан в Chromium (Playwright) по 5 сценариям, 55 проверок —
  живой сервер, пустой сервер, офлайн, выбор области, телефон. Сервер имитировался по контракту API со строгой
  проверкой полей каждого запроса; данные — настоящие отчёты из `backend/reports`. Вместо `maplibre-gl`,
  `lucide-react` и `papaparse` стояли тестовые заглушки.
- `frontend/tests/format.test.mjs`, `api.test.mjs` — проходят. `firelayers.test.mjs` — пройден без проверки схемы стиля.
- Алгоритм слияния в события: 6 тестов чистой логики из `backend/tests/test_events.py` проходят.
- Весь Python компилируется; статический анализ не нашёл неопределённых имён.

Не запускалось и должно быть проверено у вас:

- `python -m pytest -q` в `backend/` — 40 прежних тестов и новые тесты эндпоинтов.
- `npm ci && npm test && npm run build` в `frontend/` — сборка Vite и проверка стиля слоёв карты настоящей библиотекой.
- Отрисовка новых слоёв карты настоящим MapLibre и реальный запрос к NASA FIRMS с вашим ключом.
